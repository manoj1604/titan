# Getting started

The full step-by-step guide is in **[docs/guide](README.md)**. In short:

```bash
brew install manoj1604/titan/titan      # 1. install          → guide/01-install.md
titan setup                             # 2. ready your Mac   → guide/01-install.md
titan new shop --template vite          # 3. a new project    → guide/03-first-project.md
npm run dev                             #    runs in its VM → http://localhost:5173
```

Already have a project? `cd` into it and run `titan up`, or just run your usual commands if
it has a `devcontainer.json`. See [Use Titan with an existing project](guide/04-existing-projects.md).
